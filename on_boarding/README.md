# 품질 온보딩 네비게이터

SI 프로젝트 신규 입사자를 위한 **유형·단계별 품질 활동 가이드** 앱입니다.
프로젝트 유형과 단계를 고르면 해당 단계의 품질 활동(산출물, 필요 역량, 품질팀 R&R)을 조회하고,
셀프 체크로 진행 상황·마감일·코멘트를 관리할 수 있습니다. 용어사전도 함께 제공합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `UI_Test.py` | Streamlit 화면 (유형/단계 선택, 가이드 조회, 셀프 체크, 용어사전) |
| `loader.py` | SQLite DB 읽기·쓰기 및 조회/검색/CRUD 함수 |
| `quality_onboarding_navigator.db` | 데이터와 진행 상황이 들어 있는 SQLite DB |
| `build_db.py` | DB를 처음부터 다시 만드는 시드 스크립트 |

세 개(`UI_Test.py`, `loader.py`, `.db`)는 **반드시 같은 폴더**에 있어야 합니다.

## 실행 방법

```bash
pip install streamlit pandas altair
streamlit run UI_Test.py
```

Python 3.10 이상이 필요합니다(`str | None` 타입 표기 사용).

## 주요 기능

1. **유형 선택 → 단계 선택**: 사이드바에서 프로젝트 유형과 단계(제안, 착수, 분석, 설계, 구축, 테스트, 전개, 종료)를 고릅니다.
2. **가이드 조회**: 단계별 활동 목록과 산출물·필요 역량·품질팀 R&R(Guiding/Doing/Feed-Back)을 봅니다. 검색어를 입력하면 선택한 유형 전체에서 제목·설명을 검색합니다.
3. **셀프 체크**: 활동별 완료 체크, 마감일, 코멘트/추가 업무를 관리합니다. 전체·단계별 진행률 차트와 기한 초과 알림을 제공합니다.
4. **용어사전**: 용어 검색, 관리자 모드에서 추가·수정·삭제가 가능합니다.
5. **관리자 모드**: 제목 옆 `🔒 관리자` 버튼에서 코드를 입력하면 용어 및 활동 내용을 수정·삭제할 수 있습니다.

## 데이터와 DB

DB에는 다음 테이블이 있습니다.

- 가이드 데이터: `project_types`, `phases`, `activities`, `glossary`
- 셀프체크 진행 상황: `progress_checked`, `progress_due_dates`, `progress_notes`

`activities`의 산출물·품질팀 역할·필요 역량·기준 참조는 JSON 텍스트 컬럼(`*_json`)으로 저장됩니다.
DBeaver 등에서 "새 연결 → SQLite → DB 파일 선택"으로 열어 직접 조회·수정할 수 있습니다.

체크 상태·코멘트·마감일은 화면에서 바꿀 때마다 자동으로 DB에 저장되므로 새로고침해도 유지됩니다.

### DB 다시 만들기

```bash
python build_db.py --force
```

- DB가 이미 있으면 `--force` 없이는 실행되지 않습니다.
- `--force`를 쓰면 **셀프체크 진행 상황과 관리자 모드에서 수정한 내용이 모두 삭제**되고 초기 데이터로 돌아갑니다.

## 알아둘 점

- 관리자 코드는 `UI_Test.py`의 `ADMIN_CODE`에 적혀 있습니다. 실수로 데이터를 고치는 것을 막는 용도일 뿐 **보안 장치가 아니며**, 배포 전에 값을 바꾸세요.
- 진행 상황은 DB 파일 하나에 저장되므로, 여러 사람이 같은 DB를 쓰면 체크 상태가 공유(덮어쓰기)됩니다. 사람마다 따로 쓰려면 각자 DB 파일 사본을 사용하세요.
- 활동·용어를 수정하면 해당 테이블이 통째로 다시 저장됩니다(데이터 양이 적어 성능 문제는 없습니다).
- `UI_Test.py`의 "데이터 파일을 찾을 수 없음" 오류 메시지는 아직 예전 JSON 파일명을 안내합니다. 실제로는 `.db` 파일 위치를 확인하면 됩니다.
